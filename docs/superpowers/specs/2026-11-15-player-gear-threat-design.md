# 玩家平均档位威胁判断 设计

日期：2026-11-15
状态：已确认（用户选择：6 槽固定分母、自动识别自己、主窗只显示平均档位）
前置：2026-11-01-albion-aware-overlay-design.md（主窗与详情面板结构延续该规格）

## 1. 背景与目标

红黑区遇到非队友玩家时，主窗显示的 IP 在未查看装备前只是「基础 IP」（不含专精）。游戏真实 IP 只在
`GetCharacterEquipment`（op143 响应）里下发，而玩家往往来不及逐个查看。

目标：在 `NewCharacter`（event 29）刚检测到玩家的那一帧，就给出一个能判断「打不打得过」的数值与颜色，
不依赖 op143，也不需要任何手动设置。

做法：改用「平均档位」（每件装备 T级 + 附魔 的平均值），并与自己的平均档位比较。

## 2. 指标定义

- **单件档位** = `T级 + 附魔`：`T5_MAIN_SWORD@2` → 7，`T8_CAPE` → 8。
- **平均档位** = 6 个战斗槽（主手 0、副手 1、头 2、衣 3、鞋 4、披风 6）的档位之和 ÷ 6。
  - 空槽按 0 计入分母（与游戏 IP 的 6 槽口径一致）。
  - 双手武器（`h2` 且 `cat=weapons` 且 `t=weapon`）在主手、副手各计一次。
  - 结果保留 1 位小数；没有任何战斗装备 → 无值。
- **数据来源**：`NewCharacter`(event 29) 的 `p40` 与 `CharacterEquipmentChanged`(event 90) 的 `p2`，
  两者都是物品 ID 数组。删除/丢失某槽视为空。
- **与基础 IP 的关系**：物品库里 `p = 300 + 100 × (T级 + 附魔)`（已核对 T4.0=700、T5.0=800、T5.2=1000、
  T8.4=1500）。所以平均档位只是基础 IP 的另一种刻度，口径与原显示一致，`平7 = 1000 IP`。

档位解析优先取物品唯一名里的 `T数字` 与 `@数字`；唯一名无法解析时回退 `(p - 300) / 100`。

## 3. 自己的基准

- 玩家表已按 `config.self_name` 识别自己（`is_self`），自己仍然保存在表里，只是不显示。
- `main` 在每批事件应用后取一次自己的平均档位，缓存在内存 `self._self_gear`。
- **换图 `store.clear()` 不清该缓存**：认出过一次就一直有效，直到程序退出或 `self_name` 变化后重新识别。
- 缓存为空时，配色退回绝对档位（见第 4 节）；识别到自己后自动切回相对比较。
- 不新增配置项，不改 `self_name` 的现有设置流程。

## 4. 配色

颜色常量放在 `overlay.py`，与现有 `IP_GREY/IP_YELLOW/IP_ORANGE` 并列：

| 颜色 | 值 | 条件（`diff = 对方平均档位 − 自己平均档位`） |
| --- | --- | --- |
| 红 | `#ff4b3e` | `diff >= +1.0`（明显更强） |
| 橙 | `#ff7a45` | `+0.5 <= diff < +1.0`（略强） |
| 黄 | `#e8c04a` | `-0.5 < diff < +0.5`（势均力敌） |
| 绿 | `#5fbe78` | `diff <= -0.5`（可打） |

- 自己基准缺失时的绝对档位：`> 7.0` 橙、`5.0 ~ 7.0` 黄、`< 5.0` 绿。
- 完全没有装备数据 → 灰 `#d6d6d6`，文字显示 `-`。
- 「平6 及以下」在自己为平7 时命中 `diff <= -0.5`，显示绿色；灰白只保留给「无数据」。

## 5. 显示

- **悬浮窗主窗**（内容宽 78px）：右侧只显示平均档位，如 `7.3`，按上表着色；字体、位置、武器图标不变。
  IP 不再出现在主窗。
- **详情面板**：保留现有 `IP: 985` 行（查看过装备后仍是真实 IP），新增一行
  `平均档位: 7.3   你: 7.0`；自己基准缺失时显示 `你: -`。
- 排序：`sort_mode=recent` / `ip` 逻辑均不变（`ip` 仍按 IP 排序）。
- `format_ip` / `ip_color` / `_item_power` 保留，供详情面板使用。

## 7. 测试要点

- 档位解析：`T8_MAIN_SWORD@4` → 12；`T5_CAPE` → 5；未知物品 → None。
- 平均档位：全 T8.0 六件 → 8.0；全 T8.4 → 12.0；T5.2 武器 + 五件 T5.0 → 5.3；双手 T8.0 + 四件 T8.0 → 8.0；
  缺披风 → 6.7；无战斗装备 → None；在可整除的套装（如全 T8.0）上 `avg == (average_ip - 300) / 100`。
- 配色：红/橙/黄/绿四个边界（+1.0、+0.5、-0.5）；无自身基准时按 7.0/5.0 绝对档位；无数据显示灰色。
- 自身基准：事件应用后写入；`ZoneChanged` 清空玩家表后仍保留；`self_name` 为空时不产生基准。
- 主窗：行文字为 `7.3` 且使用对应颜色；无装备时为 `-`。
- 详情面板：显示 `平均档位: x  你: y`，自己未知时 `你: -`。

## 8. 边界与已知限制

- 只看等级 + 附魔，不含专精与品质：专精很高的低档玩家仍可能更强；查看装备后的真实 IP 仍可在详情面板核对。
- 故意不穿披风等空槽会按 0 计入，导致平均值偏低——这是真实基础强度的如实反映，不是 bug。
- `NewCharacter` 只在进入视野时下发一次；此后换装依赖 `CharacterEquipmentChanged`，两者都缺失时保持旧值。
- 平均档位与基础 IP 是同一数据的两种刻度，因此这次改动不会让数字「变小」或「变大」，只是换了可读单位并加上相对配色。

## 9. 不做的事

- 不做圆点/逐件条等逐槽可视化。
- 不按武器加权、不引入药水/食物/背包/坐骑。
- 不做手动填写自身基准的配置项（自动识别已覆盖，缺失时用绝对档位兜底）。
- 不改动 op143 真实 IP 的解析与缓存逻辑。
